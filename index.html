安全规则（配合登录使用）

现在工具已经要求先登录才能进入，Firestore 的安全规则也应该同步收紧成"只有登录用户才能读写"。去 Firestore 的「规则」页，把内容换成：
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /students/{id} { allow read, write: if request.auth != null; } match /sessions/{id} { allow read, write: if request.auth != null; } } }
